# Implement state management

## Description

Implement app-level state and per-request state, both accessible via `request` object in endpoints and dependencies. Mirrors FastAPI's `request.app.state` and `request.state`.

- **App state**: set once at `FastExec(state={...})`, shared across all exec calls, accessible via `request.app.state`
- **Request state**: set per `exec()` call via `state={...}`, accessible via `request.state`, isolated between calls

## Acceptance Criteria

- [ ] Endpoints access app state via `request.app.state.key`
- [ ] Endpoints access request state via `request.state.key` when passed via `exec(..., state={...})`
- [ ] App state and request state are accessible simultaneously in the same endpoint
- [ ] Dependencies (not just endpoints) can access state via `request`
- [ ] Request state is isolated between `exec()` calls — no leakage
- [ ] All 5 tests in `tests/v060/test_phase3_state.py` pass
