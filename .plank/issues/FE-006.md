# Implement nested pipelines and advanced features

## Description

Implement advanced pipeline features:

1. **Multiple pipelines**: different pipelines under different prefixes coexist in the same app
2. **Nested pipelines**: `parent.include_pipeline(child, prefix=...)` — like FastAPI's nested routers
3. **Pipeline-isolated dependencies**: different pipelines have independent dependency sets
4. **Full integration**: all features (state, deps, params, caching) work together

## Acceptance Criteria

- [ ] Multiple pipelines can coexist under different prefixes, dispatch correctly
- [ ] Nested pipelines work: `parent.include_pipeline(child, prefix=...)` with correct path composition
- [ ] Different pipelines have isolated dependency sets that don't interfere
- [ ] Full integration test passes: app state + pipeline deps + endpoint deps + query params + request state + caching all work together
- [ ] All 4 tests in `tests/v060/test_phase6_advanced.py` pass
