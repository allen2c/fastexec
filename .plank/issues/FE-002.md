# Implement layered dependency injection

## Description

Implement three-layer dependency injection that cascades from outer to inner, mirroring FastAPI's `app(dependencies=) → router(dependencies=) → route(Depends())` pattern.

Each layer can declare `dependencies=[Depends(...)]`:
- **App-level**: `FastExec(dependencies=[...])` — applied to all pipelines
- **Pipeline-level**: `Pipeline(dependencies=[...])` — applied to all endpoints in that pipeline
- **Endpoint-level**: `Depends()` in function signature — applied to that endpoint only

Dependencies from all layers are resolved together and available in the endpoint function.

## Acceptance Criteria

- [ ] Endpoint-level `fastapi.Depends()` works as in current fastexec
- [ ] `Pipeline(dependencies=[Depends(...)])` injects into all endpoints in that pipeline
- [ ] `FastExec(dependencies=[Depends(...)])` injects into all pipelines
- [ ] Three layers cascade together: app → pipeline → endpoint dependencies all available in handler
- [ ] A pipeline dependency can depend on an app dependency (nested chain across layers)
- [ ] All 5 tests in `tests/v060/test_phase2_layered_deps.py` pass
