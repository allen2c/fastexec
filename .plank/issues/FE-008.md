# Implement auto validation via type hints

## Description

Implement FastAPI's signature feature: type annotations drive runtime validation.

**Input (body auto-parse)**:
- Function param typed as `Pydantic BaseModel` → body is auto-parsed and validated without explicit `Body()`
- Type coercion works (e.g. string `"25"` → int `25`)
- Nested models, `Optional`, `List`, `Union` all respected
- Multiple Pydantic params → embedded as sub-keys in body

**Output (response auto-validate)**:
- Return type annotation as Pydantic model → response is serialized and filtered (extra fields stripped)
- Return type `List[Model]` → each item serialized
- Invalid return value raises error

This is the essence of FastAPI's developer experience: typing IS the schema.
