# Implement request parameter passing

## Description

Support passing query parameters, headers, and body through `exec()`, matching FastAPI's parameter extraction behavior. Parameters are injected into endpoints via `fastapi.Query()`, `fastapi.Header()`, `fastapi.Body()`, and Pydantic model type hints.

```python
result = await app.exec(
    "/path",
    query_params={"q": "search"},
    headers={"Authorization": "Bearer token"},
    body={"name": "Alice"},
)
```

## Acceptance Criteria

- [ ] `query_params` dict is accessible via `fastapi.Query()` in endpoint signatures
- [ ] `headers` dict is accessible via `fastapi.Header()` in endpoint signatures
- [ ] `body` dict is accessible via `fastapi.Body()` in endpoint signatures
- [ ] Pydantic model as body type hint auto-parses the body
- [ ] `query_params`, `headers`, and `body` can all be used together in a single `exec()` call
- [ ] All 5 tests in `tests/v060/test_phase5_request_params.py` pass
