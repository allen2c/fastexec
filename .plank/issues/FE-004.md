# Implement request-scope dependency caching

## Description

Ensure dependencies are cached within the scope of a single `exec()` call. If multiple dependants reference the same dependency, it is resolved exactly once. This is FastAPI's default behavior via `solve_dependencies()` and must be preserved in the new architecture.

Cache must NOT be shared across separate `exec()` calls — each call gets a fresh resolution context.

## Acceptance Criteria

- [ ] A dependency used by multiple dependants is called exactly once within a single `exec()`
- [ ] Each `exec()` call gets a fresh dependency cache (no cross-call leakage)
- [ ] Cross-layer caching works: same dependency referenced at pipeline-level and endpoint-level is cached
- [ ] Deep DAG chains (6+ nodes) each resolve exactly once per `exec()`
- [ ] All 4 tests in `tests/v060/test_phase4_caching.py` pass
