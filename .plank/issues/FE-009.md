# Remove legacy API and finalize breaking changes

## Description

Clean up the codebase after all new features are implemented:

1. Remove the old `FastExec(call=fn)` single-callable API
2. Remove `exec_with_dependant()` standalone function
3. Update `__init__.py` exports to reflect new public API: `FastExec`, `Pipeline`
4. Remove old test files (`tests/test_fast_exec.py`, `tests/test_exec_with_dependant.py`)
5. Update `README.md` with new usage examples
6. Ensure `get_dependant` is either removed or kept as a utility if still useful

This is a breaking change — v0.6.0 is not backward compatible with v0.5.x.

## Acceptance Criteria

- [ ] Old `FastExec(call=fn).exec()` API is removed
- [ ] `exec_with_dependant()` standalone function is removed
- [ ] `__init__.py` exports `FastExec` and `Pipeline` as the public API
- [ ] Old test files are removed
- [ ] No import errors when running `from fastexec import FastExec, Pipeline`
- [ ] All v060 tests pass with the final clean codebase
